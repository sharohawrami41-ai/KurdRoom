KurdRoom — Faster AI tools: live streaming, loading animation, follow-up chat, design images
============================================================================================

WHAT'S NEW
1) LOADING ANIMATION — the tool now shows an animated "Thinking…" indicator the moment
   you press Run, so it never looks frozen again.
2) FASTER ANSWERS — answers now STREAM in word-by-word as the AI writes them (instead of
   waiting for the whole reply). It feels much faster and you can start reading immediately.
3) FOLLOW-UP / REPLY BOX — after every answer there's a box to reply: "make it shorter",
   "give me more detail", "change the material to concrete", etc. The AI remembers the
   conversation and continues. Press Enter or Send.
4) DESIGN IMAGES — the AI Design Studio now also generates a PICTURE of the design
   (for the "Full concept" and "Space planning" focuses), with a "New image" button to
   get another version and a "Download" link. Answers are now nicely formatted (headings,
   bullets) instead of plain text.

WHERE IT APPLIES
- AI Design Studio, AI Summarizer, Presentation Builder, Exam Predictor (the Plus tools)
- The main AI Assistant

FILES CHANGED (5)
  app.py                       (streaming API /api/ai_stream, streaming AI call, prompts, i18n)
  templates/base.html          (loader CSS, shared streaming JS, Markdown + image helpers)
  templates/tools_plusai.html  (streaming UI + follow-up box + design image)
  templates/tools_ai.html      (streaming UI + follow-up box)
  static/sw.js                 (cache bumped to v13 so devices load the new version)

HOW TO APPLY
  Replace these 5 files in your project, then restart the app. Reopen the app once on
  your phone so the new version loads (the cache bump forces this automatically).

HOW THE IMAGES WORK (please read)
- Text answers use YOUR Anthropic API key, exactly as before — nothing to change there.
- The design PICTURES are generated by a free image service (Pollinations.ai) straight
  in the browser, so there is NOTHING to set up and no extra key needed. It works out of
  the box. Note: a free service can occasionally be slow or produce an odd image — tap
  "New image" to regenerate. When you're ready to be truly best-in-class, we can plug in
  a premium image model (higher quality, faster) behind an image API key — just ask.

TECHNICAL NOTES
- New endpoint: POST /api/ai_stream (streams text/plain). Old page routes still work as a
  no-JavaScript fallback.
- Default model stays claude-haiku-4-5 (fast). Streaming is what makes it feel instant.
